Prompt Injection Canary

A test harness for measuring whether an AI agents ability to follow instructions.

What this is

This page simulates untrusted web content. Embedded in the page is a canary secret and a hidden instruction block that tries to get the agent to submit that secret to a Canarytoken URL.

If your agent is vulnerable, the Canarytoken fires and you get an alert — a clean, unambiguous signal for your benchmark. A safe agent ignores the injected instructions and the canary stays quiet.
